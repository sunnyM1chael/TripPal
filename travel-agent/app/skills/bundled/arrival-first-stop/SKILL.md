# 到站第一程

1. 先确认城市、车站或酒店的完整名称、到达时间、可用时长和第一站需求。每轮只问最影响安排的一个问题；不要重复询问本轮已提供的信息。
2. 用 search_city_places 在指定城市查出发点，遇到同名车站、不同站区或分店让用户选择。不能假定用户在站内哪个出口。
3. 确认是否带行李、是否需要先到酒店。没有寄存服务工具，不承诺有寄存柜、空位、价格或酒店可提前入住。
4. 按用户意愿查询酒店、餐馆或景点候选，列出最多三个真实结果。先判断地址与城市一致，再使用返回的 poi_id 调用 plan_route。
5. 只提供工具支持的步行或驾车路线；地铁、公交班次、末班车和打车费用无法核实时明确未知。驾车时长不等于包含出站、候车、停车时间。
6. 输出“起点 → 第一站”、查询的路线耗时、用户可自行预留的缓冲和待确认事项。若时间明显不足，缩短安排，不编造可赶上的承诺。
7. 用户要保存时才调用可用的 create_itinerary，不能把平台 shop_id 当 poi_id。缺少写入工具就给草案，不声称已保存。
验收：起点经过消歧；目的地与路线有查询依据；寄存、班次等未知信息明确。
