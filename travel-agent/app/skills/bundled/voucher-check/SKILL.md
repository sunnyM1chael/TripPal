# 优惠券核查

1. 确认真实平台商户及用餐人数、预计消费、使用日期。若只有店名，用 search_shops 和 shop_detail 确认地址；不将高德poi_id当shop_id。
2. 用 shop_vouchers 查优惠券。展示券名、购买价、面值、有效期、使用规则及原始状态；没有信息就写未知。
3. 区分面值与购买价，单张名义差额等于面值减购买价，不等于实际省下的金额。检查最低消费、可用时段、节假日、预约和叠加规则；未提供时不自行补全。
4. 多店比较可用 compare_shops，说明当前数据的查询范围。库存与券状态仅为查询结果，不承诺可购买、一定抢到或自动核销。
5. 输出“已查到／待确认”的简明清单，告诉用户到商户购买页确认实时条件。禁止下单、付款、抢券或声称已设置到券提醒，因为当前没有这些工具。
6. 若用户想结合路线挑店，查询真实高德地点并核对地址后再 plan_route，不用优惠力度替代距离证据。
验收：金额单位明确；规则缺失可见；没有执行购买或虚构提醒。
