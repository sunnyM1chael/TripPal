# 亲子慢游

1. 确认城市、同行人员年龄范围、可接受的步行时间、是否推车或需要无障碍设施、出发点与总时长。只问影响选点的缺失信息，不采集身份资料。
2. 用 search_city_places 找两至三个候选。不能根据“亲子”店名推断适龄、安全、厕所、电梯或母婴室；未知设施请用户向场馆确认。
3. 用 plan_route 查步行或用户认可的驾车路线。高德步行路线不等于无障碍路线，不保证轮椅或推车可达。
4. 每一至两站预留休息；停留时长明确为建议，不假装实时排队数据。若路程过长，减少地点，不自动改为打车。
5. 用餐需确认忌口并查询真实商户；不能承诺无过敏原。列出餐饮、交通、门票未知费用。
6. 输出轻松主线与可跳过的一站，说明出发前需确认的设施、预约和营业时间。要求保存时使用 create_itinerary，已有行程先 get_current_itinerary，保留已完成站点再调整。
验收：有休息、有可跳过站点、无未经核实的设施承诺。
