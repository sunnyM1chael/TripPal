# 雨天备选

1. 说明当前没有实时天气查询工具；仅以用户提供的下雨、高温或天气预报为规划条件，不编造降雨概率与预警。
2. 询问城市、当前位置、剩余时间以及是否已有行程。有行程时先 get_current_itinerary，只考虑未完成站点。
3. 用 search_city_places 查询博物馆、展馆、商场等室内候选。名称不代表全程有遮蔽；室内属性、预约、门票和开放情况缺证据就标为待确认。
4. 用 plan_route 查询替代路线。步行段仍可能淋雨，不把驾车路线说成已含实时路况；遇到用户告知的危险天气，优先建议暂停出行和查看官方预警，不规划冒险路线。
5. 展示原安排、替代地点、已知路程变化与待确认项。用户表达更换意图后才 edit_current_itinerary，用最新revision与真实poi_id；不修改已完成部分。
6. 工具失败保留原计划并说明失败，不能声称已调整。没有行程工具时只提供备选草案。
验收：天气来源明确；只调整后续安排；替代地点与路线均经过查询。
